# MSA GBR Meet 2026 – Raffle & Spot Prizes

A mobile-friendly static website for GitHub Pages. No paid hosting or backend needed.

## Publish on GitHub Pages

1. Create a new public GitHub repository (for example `msa-gbr-meet-2026`).
2. Upload **all four files** from this folder to the root of the repository: `index.html`, `styles.css`, `script.js`, and `msa-raffle.jpg`.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
5. Your page will appear at `https://YOUR-USERNAME.github.io/msa-gbr-meet-2026/` once GitHub finishes publishing.

To change prizes or wording, edit `index.html`. To change colours, edit the CSS variables at the top of `styles.css`. To update the poster, replace `msa-raffle.jpg` with an image of the same filename.

The countdown is set to Queensland time (UTC+10), beginning 14 November 2026 and ending 16 November 2026.
